## 每篇文章的固定检查

1. 使用文章标题、正文、封面或截图、摘要、标签、分类和公开设置创建平台发布任务。
2. 在文章正文真实上传至少一张本地图片，确认平台托管 URL 与编辑器渲染。
3. 在末尾追加完整 JavaPub 作者介绍；不得发布内部实现、自动化、测试、路径或凭证信息。
4. 成功后打开公开页，核验标题、正文图片和作者尾注，并记录公开链接。
5. 遇到登录、人机检测或二次认证时，停止受阻操作并保留原页面等待用户完成。

本清单是平台运行状态，不代表文章已经写入当前项目仓库；文章是否备份到 Git 仓库由每篇文章的发布要求单独决定。
