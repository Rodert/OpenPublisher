# OpenPublisher

AI-native content publishing infrastructure.

OpenPublisher aims to support one-write, multi-platform publishing from a normalized Markdown article. The project is currently at the architecture/scaffolding stage.

## Repository layout

```text
src/openpublisher/       Python domain models and adapter interfaces
skills/platforms/        Platform-specific publishing rules
docs/                    Architecture and product decisions
tests/                   Automated tests
```

See [docs/consensus.md](docs/consensus.md) for the current agreed direction.
